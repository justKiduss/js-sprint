# Day 1: Counter App
## Description
todo list app with checkbox to approve you done, localstorage to store your todo info from checking done or not to the lists and a delete button use to delete the lists.buttons.
## Features
- Shows lists and if it done or not.
- checkbox checks if it done or not.
- delete button to discard the list not needed
- Persists todo through refresh.
