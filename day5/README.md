Day 5: Calculator
Description
App to perform basic calculations (add, subtract, multiply, divide) with result display.
Features
Inputs: Two numbers, operation (add/subtract/multiply/divide).
Display: Show results in list (e.g., "5 + 3 = 8").
Validate: Reject non-numbers, division by zero.
Challenges
DOM manipulation, loop iteration, input validation.
Exercises
freeCodeCamp: Complex objects, nested objects, record collection, for loops, nested loops.
LeetCode: Add Two Numbers, Two Sum.
