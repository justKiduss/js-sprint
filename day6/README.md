Day 6: Weather App
Description
App to fetch and display weather data for a city using OpenWeatherMap API.
Features

Input: City name.
Display: City, temperature (°C), weather description.
Validate: Non-empty input, API errors.

Challenges

Async/await, API fetching, error handling.

Exercises

freeCodeCamp: Async, Promises, fetch.
LeetCode: Promise Time Limit, Sleep.
