Day 7: Task Manager

Description

App to add, delete, mark completed tasks with localStorage.

Features





Add tasks (validate non-empty).



Toggle completed (strikethrough).



Delete tasks.



Persist in localStorage.

Challenges





ES6 features, array methods.

Exercises





freeCodeCamp: ES6 (arrow functions, destructuring, spread, template literals, let/const, classes, modules, Promises).



LeetCode: Array Prototype Last, Group By.
