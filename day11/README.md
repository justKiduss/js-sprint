Day 11: React Todo List
Description

A simple Todo List built with React using functional components and hooks. Users can add tasks, mark them as done, and delete tasks. The app demonstrates controlled inputs, state management, list rendering, and conditional rendering.

Features

Add tasks with controlled input

Prevent adding empty or duplicate tasks

Mark tasks as done with checkbox toggle

Delete tasks

Dynamic list rendering with unique keys

Usage

Type a task in the input field.

Click Add Task to add it to the list.

Toggle checkbox to mark a task as done.

Click Delete to remove a task.

Key Concepts Practiced

useState for state management

Controlled components

List rendering with .map()

Conditional rendering

Spread operator (...) for state updates

Error handling with temporary messages

Notes

Tasks are uniquely identified using Date.now()

Errors disappear after 3 seconds using setTimeout

State updates are immutable
