Day 4: Contact Form

Description

App to collect and display contact form submissions with localStorage persistence.
Features
Inputs: name (min 2 chars), email (valid format), message (min 5 chars).
Display/delete submissions.
Persist in localStorage.
Challenges
Object storage, form validation.
Exercises
freeCodeCamp: Object creation, access, update, delete, lookups, hasOwnProperty, this, nested objects.
LeetCode: Create Hello World, Counter.
